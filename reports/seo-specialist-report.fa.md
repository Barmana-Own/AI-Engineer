## نقش متخصص سئو

نقش canonical با شناسه `seo_specialist` به‌عنوان کارمند پایدار و فقط‌خواندنی به SEO Manager، نقش‌نامه، گراف وظایف، گذرگاه پیام، handoff، صف کار و حافظه پروژه موجود متصل شد. این نقش تحلیل جزئی و راستی‌آزمایی انجام می‌دهد و تغییرات Production همچنان متعلق به نقش‌های مهندسی و مستندسازی است.

## قابلیت‌ها و قالب یافته

تحلیل Technical SEO و On-Page، تحلیل intent و کلمات کلیدی، خوشه‌بندی، نگاشت کلیدواژه به صفحه، تشخیص cannibalization، شکاف محتوا و brief، لینک‌سازی داخلی، structured data و بررسی indexability/crawlability پشتیبانی می‌شود. `SEOFinding` شامل category، severity، resource، description، evidence، impact، recommended action، responsible role، acceptance criteria، verification method، priority و status است.

## گردش کار و handoff

- مشاهدات فنی و on-page به پیام‌های evidence ذخیره‌شده تبدیل می‌شوند.
- خوشه‌ها و نگاشت صفحات در محدوده پروژه ذخیره می‌شوند و هدف صفحه تکراری با وضعیت `cannibalization` علامت‌گذاری می‌شود.
- شکاف محتوا و brief به SEO Manager پیشنهاد می‌شوند.
- درخواست پیاده‌سازی با همان task، صف و handoff موجود به نقش مسئول واگذار می‌شود.
- راستی‌آزمایی خروجی مشاهده‌شده و مورد انتظار را مقایسه می‌کند؛ اختلاف، `SEO_FAILED` و handoff اصلاحی می‌سازد و تطابق همراه evidence، `SEO_VERIFIED` است.
- فقط نتیجه تأییدشده می‌تواند حافظه پروژه را از مسیر موجود و evidence-gated ارتقا دهد.

## مجوزها و ایمنی

مجوز نقش `READ_ONLY` و محدوده نوشتن `none` است و ابزار نوشتن Production ندارد. ادعاهای بدون منبع درباره رتبه، ترافیک، Search Console، Analytics، حجم جست‌وجو، CPC، سختی، ایندکس یا Core Web Vitals با `DATA SOURCE REQUIRED` علامت‌گذاری می‌شوند. شناسه پروژه برای تحلیل، راستی‌آزمایی و ارتقای حافظه کنترل می‌شود.

## پایگاه داده و API

جدول یا سامانه موازی اضافه نشد. پیام‌ها، taskها، صف‌ها، handoffها و حافظه تجربه SQLite موجود همه خروجی‌ها را ذخیره می‌کنند. API فهرست نقش‌ها پس از reload سرویس، نقش canonical را نمایش می‌دهد.

## آزمون‌ها

۱۱ آزمون قطعی برای مجوز نقش، یافته فنی، تحلیل on-page، خوشه‌بندی و جداسازی پروژه، شکاف و brief محتوا، لینک داخلی، درخواست پیاده‌سازی، چرخه راستی‌آزمایی و اصلاح، جلوگیری از ادعای تحلیلی جعلی، ارتقای حافظه و ایزولاسیون پروژه اضافه شد. کل آزمون‌های Orchestrator شامل ۲۲۴ آزمون با یک آزمون skip‌شده قبلی موفق شد؛ Model Gateway شامل ۲۶ آزمون و Local Agent شامل ۲ آزمون نیز موفق شدند.

## محدودیت‌های شناخته‌شده

Crawler، Analytics، Search Console، ranking و Core Web Vitals خارجی به‌صورت ضمنی متصل نیستند و تا زمان ارائه منبع مجاز، `DATA NOT AVAILABLE` باقی می‌مانند. متخصص درخواست و رکورد راستی‌آزمایی را ایجاد می‌کند اما سورس برنامه را تغییر نمی‌دهد و انتشار خارجی انجام نمی‌دهد.
