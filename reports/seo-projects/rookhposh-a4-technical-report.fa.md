## شواهد وضعیت

پایگاه دادهٔ معتبر Orchestrator در حال حاضر یک snapshot برای سایت اصلی، صفر `agent_tasks` برای پروژهٔ `04469407-8792-4ef9-b514-bbd6b91fc4b5` و صفر memory پروژه را نشان می‌دهد. A2 به‌دلیل نبود runtime واقعی Agent Worker اجرا نمی‌شود؛ A3 نیز به‌دلیل ناپایداری foundation و بازبودن تصمیم جایگاه تجاری مالک اجرا نمی‌شود.

## طراحی چرخهٔ نگه‌داشته‌شده برای بعد

پس از فعال‌سازی، چرخه باید snapshotهای محدود را مقایسه کند، نوسان‌های بی‌اهمیت را حذف کند، finding را با منشأ بسازد، فقط کار موجه را از worker واقعی عبور دهد، تست و re-audit بخواهد و فقط lessonهای معتبر را promote کند. سیگنال‌های provider باید از دادهٔ unavailable جدا بمانند.
